# Mars Orbit Tracker

A professional-grade 3D visualization of satellites and natural moons orbiting Mars, powered by NASA JPL Horizons data.

## Project Structure

- `src/fetch_data.py`: Python engine to retrieve orbital vectors from NASA.
- `src/App.jsx`: React/Three.js frontend for 3D rendering.
- `public/trajectories.json`: Cached orbital data (generated by the engine).

## Setup Instructions

### Backend Data Engine
1. Create a virtual environment: `python3 -m venv venv`
2. Activate: `source venv/bin/activate`
3. Install dependencies: `pip install -r requirements.txt`
4. Fetch data: `python3 src/fetch_data.py`

### Frontend Visualizer
1. Install Node dependencies: `npm install`
2. Start the development server: `npx vite`
